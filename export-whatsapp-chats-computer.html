How to export WhatsApp chats on a computer

A practical desktop Chrome workflow for saving conversations from your own authenticated WhatsApp Web session.

Before you begin

You need Google Chrome, WA Exporter installed, and a WhatsApp Web session linked through WhatsApp's normal sign-in process. WA Exporter does not bypass authentication or unlock unavailable history.

1. Open the conversation

Open WhatsApp Web and the chat you are authorized to export. For older history, allow WhatsApp Web time to load the messages you need before starting.

2. Start WA Exporter

Open the WA Exporter extension and choose the export action. Free supports up to three successful single-chat TXT exports per day. PRO adds more formats, custom date ranges and multi-chat workflows.

3. Choose a format and date range

Choose an output offered by your plan. WA Exporter supports TXT, PDF, CSV, HTML, ZIP and vCard workflows depending on the selected feature. Preset ranges are available, while PRO also provides custom date controls.

4. Review the downloaded file

The requested export is generated locally in the browser and saved through Chrome. Open the resulting file and confirm the required history is present before treating it as an archive.

Troubleshooting

  • If older messages are absent, return to WhatsApp Web and allow the required history to load.
  • If an export is interrupted, PRO supports resume where available.
  • If a problem continues, report the extension version, Chrome version, selected feature and error, without sending private chats, phone numbers, payment details or full license keys.
Mobile note

WA Exporter is a Chrome extension designed around WhatsApp Web on a computer. Use desktop Chrome for the export workflow.
