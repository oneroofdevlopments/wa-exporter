Support

WA Exporter – WhatsApp Chat Export & Backup

Need help?

Support is handled through the project’s public GitHub repository and the Chrome Web Store support channel once the extension is published.

Open a support issue on GitHub →

Before opening a support request

  • Confirm you are using the latest version of Chrome and WA Exporter.
  • Refresh WhatsApp Web and retry the export.
  • For long chats, allow the extension time to load older history and expand long messages.
  • Do not post private WhatsApp conversations, phone numbers, license keys, payment details or other sensitive information publicly.

Useful information to include

  • WA Exporter version
  • Chrome version
  • Export type being used
  • Whether the issue affects one chat or multiple chats
  • A privacy-safe screenshot with personal information removed

Security reports

For security-related issues, review the published security contact information and avoid posting sensitive exploit details publicly.
