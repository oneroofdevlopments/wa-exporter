Subscriptions and cancellations

For subscription billing, renewal, cancellation, invoices or license-key retrieval, use the Manage WA Exporter PRO page. The secure customer portal is hosted by Dodo Payments, so WA Exporter does not need to collect your payment information.

Before contacting support

  • Confirm you are using the latest version of Chrome and WA Exporter.
  • Refresh WhatsApp Web and retry the export.
  • For long chats, allow the extension time to load older history and expand long messages.
  • Do not send passwords, payment-card details, full private conversations or other unnecessary sensitive information.

Useful information to include

  • WA Exporter version
  • Chrome version
  • Export type being used
  • Whether the issue affects one chat or multiple chats
  • A privacy-safe screenshot with personal information removed

Security reports

Security issues can also be reported privately to support@waexporter.in. Please avoid publishing sensitive vulnerability details publicly.
